# АвтоАналоги на Windows — без Docker

Это самостоятельный вариант: локальный **MySQL Server 8.4**, **Python 3.12 x64** и веб-сервер **Waitress**. Docker Desktop, WSL и отдельный веб-сервер устанавливать не нужно.

## 1. Установите Python

Скачайте **Python 3.12, Windows installer (64-bit)** с официальной страницы: https://www.python.org/downloads/release/python-31210/.

В установщике включите **Add python.exe to PATH** и установку Python Launcher. Скрипт поддерживает как `py -3.12`, так и подходящий `python` в PATH. Для этого комплекта используйте именно Python 3.12 x64: готовый драйвер MySQL проверен для этой версии.

## 2. Установите MySQL Server

Официальная загрузка **MySQL Community Server 8.4 LTS**: https://dev.mysql.com/downloads/mysql/8.4.html. Выберите Windows x64 и MSI-установщик. Если предложен вход в Oracle, можно воспользоваться ссылкой **No thanks, just start my download**.

В настройке MySQL:

- оставьте порт **3306**;
- задайте и запомните пароль администратора **root**;
- установите MySQL как службу Windows и включите её запуск при старте компьютера;
- для работы только на этом компьютере открывать порт во входящем брандмауэре не требуется.

MySQL Workbench необязателен. Не устанавливайте второй сервер MySQL, если он уже есть: используйте его, указав правильный порт в `.env`. Поддерживается MySQL 8.4; этот комплект не рассчитан на MariaDB вместо MySQL.

## 3. Распакуйте и настройте приложение

1. Распакуйте **весь** архив в новую папку, например `C:\AutoAnalogsNative`. Файлы нельзя запускать прямо из ZIP.
2. Дважды щёлкните **install-windows-native.cmd**. Готовые Python-пакеты включены в архив, папка `vendor\wheels`: скрипт установит их локально, проверяя SHA-256. Интернет для этого шага не нужен. Скрипт создаст `.venv` и локальный файл `.env` со случайными паролями приложения.
3. Когда появится `MySQL root password`, введите пароль **root**, заданный при установке MySQL. Ввод скрыт: символы и звёздочки не показываются. Нажмите Enter. Этот пароль используется только для настройки, не записывается в файл и не передаётся веб-приложению.
4. Скрипт создаст базу `autoparts` с utf8mb4 и отдельную MySQL-учётную запись `autoparts`, применит миграции, соберёт статические файлы, создаст администратора сайта и загрузит предоставленный каталог.
5. Дождитесь сообщения `Installation complete`.

Если имя базы или пользователя `autoparts` уже занято вашим другим приложением, до настройки укажите отдельные `MYSQL_DATABASE` и `MYSQL_USER` в `.env`. Скрипт не сбрасывает пароль существующего пользователя MySQL: при несовпадении остановится с пояснением. Не используйте `root` как `MYSQL_USER`.

Если порт MySQL отличается от 3306, после первого создания `.env` измените `DB_PORT` и повторите установку. При проблеме с соединением скрипт не изменяет базу.

## 4. Запустите сайт

Дважды щёлкните **start-windows-native.cmd**. Браузер откроет `http://localhost:8000`. Окно запуска оставьте открытым: пока оно работает, работает и сайт.

- Логин сайта: **admin**.
- Начальный пароль сайта: значение после `DJANGO_SUPERUSER_PASSWORD=` в файле `.env`. Откройте `.env` через Блокнот и скопируйте только значение после `=`. Это **другой пароль**, не MySQL `root`.
- После входа нажмите **admin** и смените пароль. С этого момента пользуйтесь новым паролем; начальное значение в `.env` не обновляется.
- Учётные записи создавайте в **Управление → Пользователи**. Без флага «Статус персонала» пользователь сможет только искать и просматривать каталог.

Повторная настройка сохраняет `.env`, существующие пароли и заполненный каталог. Если связь с базой уже работает, пароль MySQL `root` повторно не запрашивается.

## Ежедневная работа и остановка

Запускайте **start-windows-native.cmd**. Служба MySQL должна работать. Для остановки сайта нажмите **Ctrl+C** в его окне; при запросе Windows подтвердите завершение пакетного файла. Можно также закрыть окно запуска. Служба MySQL при этом продолжает работать, записи сохраняются.

Веб-интерфейс доступен только на этом компьютере. Интернет после установки для поиска в локальном каталоге не нужен. Доступ с других компьютеров здесь не настроен.

## Каталог и данные

В архив включён предоставленный `data/example.csv`: **1000 связей, 1004 детали, 189 производителей**. Названий деталей и применяемости в исходном файле нет; их можно дополнить вручную.

Полный каталог импортируется через **Импорт CSV → Каталог связей (формат example.csv)**. За раз — до 5000 строк и 2 МБ. Для большого каталога разбейте файл на части, сохраняя строку заголовков в каждой. Ошибка отменяет весь импорт текущего файла.

База хранится в каталоге данных установленного MySQL, а не внутри папки приложения. Копирование папки приложения не переносит изменения базы. Делайте резервные копии средствами MySQL. Например, в обычной командной строке CMD (укажите фактический путь к установленному `mysqldump.exe`):

```bat
"C:\Program Files\MySQL\MySQL Server 8.4\bin\mysqldump.exe" --host=127.0.0.1 --port=3306 --user=autoparts --password --no-tablespaces --single-transaction --result-file=backup.sql autoparts
```

При запросе введите **MYSQL_PASSWORD из `.env`**, а не пароль сайта. Используется `--result-file`, чтобы вывод PowerShell не менял кодировку SQL. Если имя базы, пользователя или порт изменены, подставьте свои значения. SQL-копия содержит данные пользователей; храните её вместе с `.env` в защищённом месте.

## Если что-то не работает

- **Python не найден:** установите Python 3.12 x64 с Launcher или PATH, затем повторите запуск. После изменения PATH откройте новое окно терминала.
- **Cannot reach MySQL:** в Windows нажмите Win+R, введите `services.msc`, найдите службу MySQL и запустите её. Проверьте `DB_PORT` в `.env`.
- **Access denied for user root:** проверьте пароль root. Изменения существующей базы и пароль root скрипт не сбрасывает.
- **Application account already exists:** задайте правильный `MYSQL_PASSWORD` существующего пользователя либо выберите отдельное незанятое имя `MYSQL_USER` и повторите настройку.
- **Порт сайта занят:** добавьте строку `APP_PORT=8001` в `.env`. После повторного запуска сайт откроется на новом порту.
- **Забыли пароль сайта:** откройте CMD в папке приложения и выполните `.venv\Scripts\python.exe manage.py changepassword admin`. Введите новый пароль дважды. Чтобы снять блокировку входа, выполните `.venv\Scripts\python.exe manage.py axes_reset_username admin`.
- **Нужны тесты:** приложение запускается с ограниченным пользователем базы, который не может создать отдельную тестовую БД. Для автоматических тестов нужен отдельно разрешённый тестовый MySQL-доступ. Не переключайте обычный запуск сайта на root.

Не удаляйте `.env`, если хотите сохранить подключение к существующей базе. Установка и запуск не требуют отключения TLS или проверки подписи пакетов. Если возникнет ошибка, пришлите её текст без паролей.

Если вы используете исходники из репозитория без папки `vendor\wheels`, установщик скачивает зависимости из PyPI; для этого потребуется интернет. В архиве Windows все зависимости, включая данные часовых поясов для Windows, и файл контрольных сумм уже включены. Работа обычного Python-процесса с MySQL и Waitress проверена в облачной Linux-среде; непосредственно на Windows установщик здесь не выполнялся.
