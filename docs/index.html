Ориентир: «Кузаў (рама) №». Снимите эту строку и VIN после неё крупно, без бликов. Фото распознаётся в браузере. Для первого запуска OCR требуется интернет. VIN с бликами может потребовать ручного ввода.

Как это работает

1. Введите 17 символов VIN, отсканируйте штрихкод или загрузите фотографию.

2. Проверьте распознанный VIN и выполните поиск.

3. Скопируйте VIN, откройте PartSouq или SoloCatalog и вставьте VIN в поиск. Выберите узел, чтобы найти OEM-номер.

Реальный подбор выполняется на сайте выбранного каталога. Для выдачи результатов внутри приложения потребуется API автокаталога. Демопример показывает только интерфейс. Запуск внутри Telegram требует настройки Mini App в вашем боте через BotFather.
