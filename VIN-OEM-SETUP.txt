VIN / OEM — самостоятельное приложение

Вход в ChatGPT, OpenAI API и сервер не требуются.
Сайт состоит из docs/index.html, docs/style.css, docs/app.js.

ПУБЛИКАЦИЯ
1. Откройте Settings > Pages этого репозитория.
2. Source: Deploy from a branch.
3. Branch: vin-oem-pages; Folder: /docs.
4. Нажмите Save и дождитесь успешной публикации.
5. Скопируйте реальный адрес по кнопке Visit site в Settings > Pages.
Не используйте корень репозитория как папку публикации: приложение находится в docs.

TELEGRAM
1. В @BotFather отправьте /setmenubutton.
2. Выберите вашего бота.
3. Отправьте HTTPS-адрес, полученный в GitHub Pages.
4. Текст кнопки: Поиск по VIN.
5. Закройте ранее открытое приложение в Telegram и запустите его заново.

ФУНКЦИИ
Ручной ввод и проверка VIN; сканирование штрихкода при наличии BarcodeDetector;
OCR фото в браузере; копирование VIN; переход в PartSouq/SoloCatalog.
Сайты каталогов требуют вставить VIN в собственный поиск. Автоматического
подбора OEM внутри приложения нет. Демо-детали не подтверждены по VIN.

Камера требует HTTPS, разрешения пользователя и поддержки браузера.
Если камера недоступна внутри Telegram, откройте сайт в Chrome/Safari,
загрузите JPG/PNG или введите VIN вручную.
OCR загружает Tesseract.js и английскую модель с внешних CDN; нужен интернет.
VIN после распознавания проверьте вручную. История и сохранённые образцы
деталей находятся только в localStorage конкретного браузера.
Токен Telegram-бота и ключи API в этих файлах отсутствуют и не требуются.
