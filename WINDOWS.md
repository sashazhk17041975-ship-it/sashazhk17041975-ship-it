# Запуск АвтоАналогов на Windows

Сайт и MySQL будут работать на вашем компьютере. Отдельная установка Python или MySQL не нужна. Интернет нужен для первой загрузки Docker-образов и зависимостей; уже установленное приложение работает с локальной базой.

## Первый запуск

1. Установите **Docker Desktop для Windows** с официального сайта: https://www.docker.com/products/docker-desktop/. Требования к версии Windows и оборудованию: https://docs.docker.com/desktop/setup/install/windows-install/. Выберите стандартный вариант с WSL 2 и Linux-контейнерами. Если установщик попросит перезагрузку, перезагрузите компьютер.
2. Запустите Docker Desktop и дождитесь готовности движка. Если он сообщает, что WSL требует обновления, выполните `wsl --update` в PowerShell от администратора и перезапустите Docker Desktop. Если WSL ещё не установлен, используйте `wsl --install` и перезагрузите компьютер. Эти действия нужны только при соответствующем сообщении установщика или Docker Desktop.
3. Распакуйте **весь** архив в отдельную папку, например `C:\AutoAnalogs`. Не запускайте файлы прямо внутри ZIP. В выбранном пути не используйте запятые: путь передаётся Docker как параметр bind mount.
4. Дважды щёлкните **start-windows.cmd**. Первое скачивание и сборка могут занять несколько минут; оставьте окно открытым. Скрипт создаст случайные локальные пароли, запустит MySQL и сайт, создаст администратора и загрузит предоставленный каталог.
5. После успешного запуска браузер откроет адрес `http://localhost:8000`.
6. Войдите с логином **admin**. Начальный пароль находится в файле `.env` в папке проекта, справа от `DJANGO_SUPERUSER_PASSWORD=`. Откройте этот файл через Блокнот; скопируйте только значение после знака `=`, без пробелов. Если файл не виден, включите отображение скрытых файлов в Проводнике. Пароль не нужно присылать в чат.
7. После входа нажмите имя пользователя **admin** и смените пароль. Новые учётные записи создаются через **Управление → Пользователи**. У обычного пользователя не устанавливайте «Статус персонала»: он сможет искать и просматривать, но не менять данные.

При повторном запуске существующий `.env`, пароль учётной записи и заполненный каталог сохраняются. После смены пароля входите с новым паролем: значение в `.env` больше не является действующим паролем учётной записи.

## Ежедневная работа

- Запустите Docker Desktop, затем **start-windows.cmd**. Откройте `http://localhost:8000`, если браузер не открылся автоматически.
- Чтобы остановить приложение, запустите **stop-windows.cmd**. Данные сохраняются.
- Закрытие вкладки браузера не останавливает базу или приложение.

Данные MySQL хранятся в Docker volume, а не в папке проекта. Не удаляйте volume в Docker Desktop и не используйте `docker compose down -v`, если данные нужны. Перенос одной папки проекта не переносит изменения в базе. Для резервного копирования используйте команды из README.md; SQL-дамп содержит данные пользователей, поэтому храните его с ограниченным доступом.

## Каталог

В архив включён предоставленный `data/example.csv`: 1000 связей, из которых создаются 1004 детали и 189 производителей. Названий деталей и применяемости к автомобилям в файле нет; их можно дополнить вручную. Полный каталог в таком же формате загружается через кнопку **Импорт CSV**, тип «Каталог связей (формат example.csv)». За один импорт — до 5000 строк и 2 МБ; большие файлы нужно разбить на части, повторив строку заголовков в каждой.

## Если не запускается

- **Docker недоступен:** запустите Docker Desktop и дождитесь готовности. Используйте Linux-контейнеры.
- **Порт 8000 занят:** закройте другое приложение, использующее этот порт, и повторите запуск. Сообщение обычно содержит `port is already allocated` или `address already in use`.
- **Ошибка скачивания или сертификата:** проверьте интернет и настройки прокси Docker Desktop. В корпоративной сети настройте доверенный сертификат по документации Docker; не отключайте проверку TLS.
- **Забыли пароль:** откройте PowerShell в папке проекта и выполните `docker compose exec web python manage.py changepassword admin`. Введите новый пароль дважды; символы ввода скрыты. При блокировке входа подождите 15 минут или выполните `docker compose exec web python manage.py axes_reset_username admin`.
- **Другая ошибка:** сохраните текст сообщения из окна запуска. Для просмотра журналов выполните из папки проекта `docker compose logs --tail=80 web db`. Перед передачей журналов убедитесь, что в них нет паролей.

Приложение привязано к локальному интерфейсу компьютера. Для доступа с других компьютеров требуется отдельная настройка сети, адреса сайта и HTTPS.
